SwiftDrop — Parcel Delivery & Courier Management

Frontend Developer, Member 6

SwiftDrop is a team-built parcel delivery platform. I built a four-step customer booking flow with server-calculated quotes and parcel tracking with SSE reconnection and polling fallback. I also integrated merchant onboarding, CSV order imports, API key management, and webhook settings, and built the SwiftDrop Assistant chat interface.

I built dispatcher tools for courier assignment and a mobile courier dashboard with delivery runs and photo proof. I fixed Go/PostgreSQL queries and verified locally that dispatchers could assign parcels and couriers could start deliveries.

I wrote two Playwright integration tests that passed against the local Core API, covering merchant sign-in, profile and order loading, and API key creation and revocation.
